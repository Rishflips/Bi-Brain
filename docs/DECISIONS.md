## Open decisions, non-blocking for local build

Public license; hosted infrastructure and identity; billing provider; first managed connector; runtime reasoning provider based on credentials and evaluation; actual prices; native desktop/mobile packaging.

Use honest unavailable/extractive states while external dependencies are absent.

## Implemented local choices, 2026-09-28

- Node 24 built-in SQLite avoids a native database addon on Windows; migrations record versions 1–3 and reject a newer unsupported database.
- The maintained official MCP SDK v1 line is pinned at 1.30.1. SDK stdio contract verification is distinct from native Codex/Claude verification.
- A project brief is the editable project understanding page; source and brief revisions use version checks. Separate empty forwarding packages and model-generated decision classification are not introduced.
- Extractive preparation offers source-linked review hypotheses, not a contradiction classifier. A provider adapter exists for briefs; paid goal-specific synthesis requires separate live evaluation before promotion.
- Portable exports use a checksummed runtime envelope containing source versions and current knowledge. Imports preserve IDs, block conflicts, disable preparation, and keep historical receipts unable to undo local edits.
- A local supervisor runs API and worker as separate processes. Docker operation remains unverified without a Docker runtime.
- Automatic paid retry stops after ambiguous usage; unresolved reservations remain held. Operator-supplied verified prices are required rather than guessed.

## Deliberate changes from brainstorming

- GUI is a core deliverable.
- First-use works before integrations.
- Database is authoritative; exports are portable.
- Manual capture is never silently discarded by System 1.
- Agent authority is scoped operations, not a broad Dream permission.
- Permanent deletion covers derivatives and caches.
- Model confidence does not grant permission.
- Native integrations are verified per client.
- Market absence, speed, pricing, and licensing claims require evidence.
