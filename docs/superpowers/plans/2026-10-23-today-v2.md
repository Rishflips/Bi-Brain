# Today v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current Today screen with the reframed one: a single save-or-ask bar, a Brief of at most three real items with Keep, Fix, Dismiss and Undo, and project cards, all backed by the existing services.

**Architecture:** A new pure domain function `buildBrief` ranks real review items (queued memory gates, corrections, goal proposals, failed preparation jobs, stale facts) and caps them at three. `Brain` gains `brief`, `dismissBriefItem`, `confirmClaim` and `ask` service methods, with thin HTTP routes. Gate review gains an owner-edited value and undo for plain accepted memories. The web app mounts a new `apps/web/today/` module in place of the old Today JSX in `apps/web/src.tsx` and leaves every other screen untouched.

**Tech Stack:** TypeScript (strict), React 19, Fastify 5, SQLite through `packages/storage`, Zod 4, Vitest 5, Playwright 1.63. No new dependencies.

**Spec:** `docs/REFRAME_BRIEF.md` (approved by the owner 2026-10-23). Visual and copy reference: `design/reframe/bibrain-reframe-prototype.html` (sample data only; do not copy its data or its simulated behaviour).

## Review Focus

1. **Acting twice on one Brief item** (double click, or a second tab): the second request gets 409, no second claim is created, and the Brief refreshes with a plain message. Pinned in Task 3 and Task 7.
2. **Undo after a later edit**: if the accepted fact was changed or retired after Keep, Undo returns 409 and nothing is overwritten. Pinned in Task 3.
3. **Original withdrawn or deleted while its item is in the Brief**: the item disappears from the next Brief, and accepting the stale copy returns `SOURCE_STALE`, shown as "The original changed. This suggestion was removed." Pinned in Task 2 (Brief drops it) and Task 3 (accept refuses it); Task 7 maps the error to that sentence.
4. **Server unreachable during save or ask**: the draft stays in the bar and an error explains it; nothing claims success. Pinned in Task 6 and Task 9.
5. **Ask with input that has no searchable words** (only punctuation, or over 500 characters): a validation message, no request storm and no crash. Pinned in Task 4 and Task 6.

```ts
// packages/domain/brief.ts
import type { Entity } from "../contracts/index.ts";

export type BriefKind = "correction" | "proposal" | "failed_job" | "agent_memory" | "memory" | "stale";
export type BriefEvidence = { source_id: string; source_version: number; quote: string };
export type BriefTarget = { type: "gate" | "proposal" | "job" | "claim"; id: string; version: number };
export type BriefItem = {
  signature: string;
  kind: BriefKind;
  project_id: string;
  title: string;
  why: string;
  before?: string;
  evidence: BriefEvidence[];
  target: BriefTarget;
  created_at: string;
};
export type BriefSourceRef = { id: string; project_id: string; body: string; captured_at: string };
export type BriefJob = { id: string; project_id: string; kind: string; attempts: number; created_at: string };
export type BriefInput = {
  gates: Entity[];
  proposals: Entity[];
  claims: Entity[];
  failedJobs: BriefJob[];
  sources: BriefSourceRef[];
  dismissed: string[];
  confirmations: Record<string, string>;
  agentNames: Record<string, string>;
};

export const BRIEF_LIMIT = 3;
export const STALE_DAYS = 21;
const MIN_STALE_MENTIONS = 2;
const RANK: Record<BriefKind, number> = { correction: 0, proposal: 1, failed_job: 2, agent_memory: 3, memory: 4, stale: 5 };

const evidenceOf = (list: unknown): BriefEvidence[] =>
  (Array.isArray(list) ? list : [])
    .filter((e) => e && typeof e.source_id === "string" && typeof e.quote === "string" && e.quote)
    .map((e) => ({ source_id: e.source_id, source_version: Number(e.source_version) || 1, quote: e.quote }));

function factText(entityName: string, aspect: string, value: unknown) {
  return aspect === "status" ? `${entityName} is ${String(value)}.` : `${entityName}: ${String(value)}`;
}

export function buildBrief(input: BriefInput, now: Date): { items: BriefItem[]; waiting: number } {
  const candidates: BriefItem[] = [];

  for (const g of input.gates) {
    if (g.data.status !== "queued") continue;
    const evidence = evidenceOf(g.data.evidence);
    if (!evidence.length || !g.data.field) continue;
    const actor = String(g.data.actor ?? "owner");
    const agent = actor.startsWith("agent:") ? input.agentNames[actor.slice(6)] ?? "A connected agent" : null;
    const correction = g.data.correction === true;
    const before = correction
      ? (g.data.conflicts ?? []).map((c: { value: unknown }) => String(c.value)).join("; ")
      : undefined;
    candidates.push({
      signature: `gate:${g.id}:${g.version}`,
      kind: correction ? "correction" : agent ? "agent_memory" : "memory",
      project_id: g.project_id,
      title: factText(String(g.data.entity), g.data.field.aspect, g.data.field.value),
      why: correction
        ? "A newer original disagrees with what you decided before."
        : agent
          ? `${agent} wrote this down while it worked.`
          : "BiBrain found this in something you saved.",
      ...(before ? { before } : {}),
      evidence,
      target: { type: "gate", id: g.id, version: g.version },
      created_at: g.created_at,
    });
  }

  for (const p of input.proposals) {
    if (p.data.status !== "ready") continue;
    const evidence = evidenceOf(p.data.evidence);
    if (!evidence.length) continue;
    candidates.push({
      signature: `proposal:${p.id}:${p.version}`,
      kind: "proposal",
      project_id: p.project_id,
      title: String(p.data.title),
      why: String(p.data.reason),
      evidence,
      target: { type: "proposal", id: p.id, version: p.version },
      created_at: p.created_at,
    });
  }

  for (const j of input.failedJobs) {
    candidates.push({
      signature: `job:${j.id}:${j.attempts}`,
      kind: "failed_job",
      project_id: j.project_id,
      title: "A saved note could not be prepared.",
      why: "Your original is safe. Try again, or open the original.",
      evidence: [],
      target: { type: "job", id: j.id, version: j.attempts },
      created_at: j.created_at,
    });
  }

  const staleBefore = now.getTime() - STALE_DAYS * 86_400_000;
  for (const c of input.claims) {
    if (c.data.status !== "current") continue;
    const evidence = evidenceOf(c.data.evidence);
    const name = String(c.data.entity ?? "").trim().toLocaleLowerCase();
    if (!evidence.length || name.length < 3) continue;
    const checkedAt = Date.parse(input.confirmations[c.id] ?? c.data.recorded_at ?? c.created_at);
    if (!(checkedAt < staleBefore)) continue;
    const mentions = input.sources.filter(
      (s) => s.project_id === c.project_id && Date.parse(s.captured_at) > checkedAt && s.body.toLocaleLowerCase().includes(name),
    ).length;
    if (mentions < MIN_STALE_MENTIONS) continue;
    const day = new Date(checkedAt).toISOString().slice(0, 10);
    candidates.push({
      signature: `stale:${c.id}:${c.version}:${mentions}`,
      kind: "stale",
      project_id: c.project_id,
      title: factText(String(c.data.entity), String(c.data.aspect), c.data.value),
      why: `Last checked ${day}. ${mentions} originals saved since then mention ${String(c.data.entity)}.`,
      evidence,
      target: { type: "claim", id: c.id, version: c.version },
      created_at: c.created_at,
    });
  }

  const dismissed = new Set(input.dismissed);
  const open = candidates
    .filter((i) => !dismissed.has(i.signature))
    .sort((a, b) => RANK[a.kind] - RANK[b.kind] || b.created_at.localeCompare(a.created_at));
  return { items: open.slice(0, BRIEF_LIMIT), waiting: Math.max(0, open.length - BRIEF_LIMIT) };
}
```

```ts
// packages/domain/ask.ts
import type { Entity, Source } from "../contracts/index.ts";
import type { BriefEvidence } from "./brief.ts";

export type AskHit =
  | { type: "fact"; id: string; project_id: string; text: string; evidence: BriefEvidence[] }
  | { type: "original"; id: string; project_id: string; title: string; snippet: string; source_version: number };

const STOP = new Set(
  "the a an and or of to in on for is are was were be do does did what when which who how we our you your it this that with about from at by not have has had any before after out into then than also more just one can will would should there their them they its get got".split(" "),
);

export function questionWords(question: string): string[] {
  const words = question.toLocaleLowerCase().match(/[\p{L}\p{N}$]+/gu) ?? [];
  return [...new Set(words.filter((w) => w.length > 2 && !STOP.has(w)).map((w) => w.replace(/s$/u, "")))];
}

function overlap(words: string[], text: string) {
  const own = new Set(questionWords(text));
  return words.reduce((n, w) => n + (own.has(w) ? 1 : 0), 0);
}

function bestSentence(body: string, words: string[]) {
  const parts = body.split(/(?<=[.?!])\s+|\n+/u).filter(Boolean);
  let best = parts[0] ?? body;
  let score = -1;
  for (const part of parts) {
    const n = overlap(words, part);
    if (n > score) { score = n; best = part; }
  }
  return Array.from(best).length > 240 ? Array.from(best).slice(0, 237).join("") + "…" : best;
}

export function rankAnswers(question: string, claims: Entity[], sources: Source[], limit = 3): AskHit[] {
  const words = questionWords(question);
  if (!words.length) return [];
  const facts = claims
    .map((c) => {
      const text = c.data.aspect === "status" ? `${c.data.entity} is ${c.data.value}.` : `${c.data.entity}: ${c.data.value}`;
      return { c, text, n: overlap(words, text) };
    })
    .filter((x) => x.n > 0)
    .sort((a, b) => b.n - a.n);
  const covered = new Set(facts.flatMap((x) => (x.c.data.evidence ?? []).map((e: { source_id: string }) => e.source_id)));
  const originals = sources
    .filter((s) => s.state === "active" && !covered.has(s.id))
    .map((s) => ({ s, n: overlap(words, `${s.title} ${s.body}`) }))
    .filter((x) => x.n > 0)
    .sort((a, b) => b.n - a.n);
  const hits: AskHit[] = [
    ...facts.map(({ c, text }) => ({
      type: "fact" as const, id: c.id, project_id: c.project_id, text,
      evidence: (c.data.evidence ?? []).map((e: BriefEvidence) => ({ source_id: e.source_id, source_version: e.source_version, quote: e.quote })),
    })),
    ...originals.map(({ s }) => ({
      type: "original" as const, id: s.id, project_id: s.project_id, title: s.title,
      snippet: bestSentence(s.body, words), source_version: s.version,
    })),
  ];
  return hits.slice(0, limit);
}
```

```tsx
import { useRef, useState } from "react";
import type { Api, AskHit } from "./types.ts";

type Props = {
  api: Api;
  projects: { id: string; title: string }[];
  onSaved: (sourceId: string) => void;
  onOpenSource: (id: string) => void;
};
type Result =
  | { kind: "saved"; sourceId: string; title: string; project: string }
  | { kind: "answer"; question: string; hits: AskHit[] }
  | null;

const LIMIT = 100_000;

export function SaveAskBar({ api, projects, onSaved, onOpenSource }: Props) {
  const [text, setText] = useState("");
  const [mode, setMode] = useState<"save" | "ask">("save");
  const [project, setProject] = useState("inbox");
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [result, setResult] = useState<Result>(null);
  const area = useRef<HTMLTextAreaElement>(null);
  const ask = mode === "ask";

  function change(value: string) {
    setText(value);
    setError(null);
    if (/\?\s*$/u.test(value)) setMode("ask");
  }

  async function submit() {
    const value = text.trim();
    if (busy) return;
    if (!value) { setError(ask ? "Type a question first." : "Type or paste something first."); return; }
    setBusy(true);
    setError(null);
    try {
      if (ask) {
        const out = await api<{ question: string; hits: AskHit[] }>(`/ask?q=${encodeURIComponent(value)}`);
        setResult({ kind: "answer", question: out.question, hits: out.hits });
        setText("");
        setMode("save");
      } else {
        if (Array.from(value).length > LIMIT) { setError("That is over 100,000 characters. Split it into smaller notes."); return; }
        const firstLine = value.split("\n")[0];
        const title = Array.from(firstLine).length > 80 ? Array.from(firstLine).slice(0, 79).join("") + "…" : firstLine;
        const saved = await api<{ source_id: string }>("/sources", { title, body: value, project_id: project });
        setResult({ kind: "saved", sourceId: saved.source_id, title, project: projects.find((p) => p.id === project)?.title ?? "Inbox" });
        setText("");
        onSaved(saved.source_id);
      }
    } catch (e) {
      const message = e instanceof Error ? e.message : "Your brain is unavailable.";
      setError(ask ? message : `Not saved. ${message} Your text is still here.`);
    } finally {
      setBusy(false);
    }
  }

  return (
    <div className="tv-bar-wrap">
      <form className="tv-bar" onSubmit={(e) => { e.preventDefault(); void submit(); }}>
        <label className="tv-sr" htmlFor="tv-bar">{ask ? "Ask your brain" : "Save to your brain"}</label>
        <div className="tv-bar-row">
          <textarea
            id="tv-bar"
            ref={area}
            rows={2}
            value={text}
            placeholder={ask ? "Ask what your brain knows…" : "Paste a note, a decision, or a conversation…"}
            onChange={(e) => change(e.target.value)}
            onKeyDown={(e) => { if (e.key === "Enter" && !e.shiftKey) { e.preventDefault(); void submit(); } }}
          />
          <button className="tv-btn tv-primary" type="submit" disabled={busy}>{busy ? (ask ? "Asking…" : "Saving…") : ask ? "Ask" : "Save"}</button>
        </div>
        <div className="tv-bar-foot">
          <div className="tv-seg" role="group" aria-label="What the bar does">
            <button type="button" aria-pressed={!ask} onClick={() => { setMode("save"); area.current?.focus(); }}>Save</button>
            <button type="button" aria-pressed={ask} onClick={() => { setMode("ask"); area.current?.focus(); }}>Ask</button>
          </div>
          {!ask && (
            <label className="tv-faint">
              Save to{" "}
              <select value={project} onChange={(e) => setProject(e.target.value)}>
                {projects.map((p) => <option key={p.id} value={p.id}>{p.title}</option>)}
              </select>
            </label>
          )}
          <span className="tv-faint">Enter to {ask ? "ask" : "save"} · Shift+Enter for a new line</span>
        </div>
      </form>
      {error && <p className="tv-error" role="alert">{error}</p>}
      {result?.kind === "saved" && (
        <div className="tv-panel" aria-live="polite">
          <span className="tv-eyebrow">Saved</span>
          <p><b>{result.title}</b></p>
          <p className="tv-faint">
            In {result.project}. The original is kept exactly as you wrote it.{" "}
            <button className="tv-link" onClick={() => onOpenSource(result.sourceId)}>Open it</button>
          </p>
        </div>
      )}
      {result?.kind === "answer" && (
        <div className="tv-panel" aria-live="polite">
          <div className="tv-section-head">
            <span className="tv-eyebrow">From your brain</span>
            <button className="tv-btn tv-ghost" onClick={() => setResult(null)}>Close</button>
          </div>
          <p className="tv-faint">You asked: <b>{result.question}</b></p>
          {result.hits.length === 0 ? (
            <p>Nothing in your brain answers that yet.</p>
          ) : (
            result.hits.map((h) => (
              <div className="tv-hit" key={`${h.type}:${h.id}`}>
                <span className={h.type === "fact" ? "tv-tag tv-ok" : "tv-tag"}>{h.type === "fact" ? "Reviewed" : "Original, not reviewed yet"}</span>
                <p>{h.type === "fact" ? h.text : h.snippet}</p>

              </div>
            ))

          <p className="tv-faint">Answers come only from what is saved here.</p>
        </div>
      )}
    </div>
  );
}
```

```tsx
// apps/web/today/useUndoToast.tsx
import { useCallback, useEffect, useRef, useState } from "react";

export function useUndoToast() {
  const [state, setState] = useState<{ message: string; undo?: () => Promise<void> } | null>(null);
  const timer = useRef<number | undefined>(undefined);
  const show = useCallback((message: string, undo?: () => Promise<void>) => {
    window.clearTimeout(timer.current);
    setState({ message, undo });
    timer.current = window.setTimeout(() => setState(null), 6000);
  }, []);
  useEffect(() => () => window.clearTimeout(timer.current), []);
  const toast = state ? (
    <div className="tv-toast" role="status">
      <span>{state.message}</span>
      {state.undo && (
        <button
          onClick={async () => {
            const undo = state.undo!;
            setState(null);
            try { await undo(); show("Undone."); }
            catch (e) { show(e instanceof Error ? e.message : "Could not undo."); }
          }}
        >
          Undo
        </button>
      )}
    </div>
  ) : null;
  return { toast, show };
}
```

```tsx
  onDone: (message: string, undo?: () => Promise<void>) => void;
  onDeferredDismiss: (item: BriefItem, send: () => Promise<unknown>) => void;
  onError: (message: string) => void;
};

const LABEL: Record<BriefItem["kind"], string> = {
  correction: "Changes an earlier decision",
  proposal: "Prepared for your goal",
  failed_job: "Needs a retry",
  agent_memory: "Written down by your agent",
  memory: "Found in something you saved",
  stale: "Still true?",
};
const KEEP: Record<BriefItem["kind"], string> = {
  correction: "Update the decision",
  proposal: "Keep this plan",
  failed_job: "Try again",
  agent_memory: "Keep as true",
  memory: "Keep as true",
  stale: "Still true",
};

export function BriefCard({ item, projectTitle, api, onOpenSource, onDone, onDeferredDismiss, onError }: Props) {
  const [fixing, setFixing] = useState(false);
  const [wording, setWording] = useState(item.title.replace(/^[^:]+:\s*/u, ""));
  const [busy, setBusy] = useState(false);
  const t = item.target;
  const gate = t.type === "gate";
  const canFix = (gate && !/ is [a-z]+\.$/u.test(item.title)) || t.type === "proposal";

  async function run(action: () => Promise<void>) {
    if (busy) return;
    setBusy(true);
    try { await action(); }
    catch (e) {
      const message = e instanceof Error ? e.message : "Your brain is unavailable.";
      onError(/SOURCE_STALE|no longer active/iu.test(message) ? "The original changed. This suggestion was removed." : message);
    } finally { setBusy(false); }
  }

  const keep = (value?: string) =>
    run(async () => {
      if (gate) {
        const r = await api<{ gate_version: number }>(`/proposals/gate/${t.id}/review`, { action: "accept", expected_version: t.version, ...(value ? { value } : {}) });
        onDone(value ? `Kept in your wording in ${projectTitle}.` : `Kept as a fact in ${projectTitle}.`, async () => {
          await api(`/proposals/gate/${t.id}/review`, { action: "undo", expected_version: r.gate_version });
        });
      } else if (t.type === "proposal") {
        const r = await api<{ receipt: { id: string; version: number } }>(`/proposals/${t.id}/accept`, { expected_version: t.version, ...(value ? { edited_artifact: value } : {}) });
        onDone("Plan kept. The earlier plan stays in history.", async () => {
          await api(`/receipts/${r.receipt.id}/undo`, { expected_version: r.receipt.version });
        });
      } else if (t.type === "claim") {
        await api(`/claims/${t.id}/confirm`, {});
        onDone("Marked as still true today.");
      } else {
        await api(`/jobs/${t.id}/retry`, {});
        onDone("Trying again. It shows here when it finishes.");
      }
    });

  const dismiss = () => {
    const send = gate
      ? () => api(`/proposals/gate/${t.id}/review`, { action: "reject", expected_version: t.version })
      : t.type === "proposal"
        ? () => api(`/proposals/${t.id}/dismiss`, {})
        : () => api("/brief/dismiss", { signature: item.signature });
    onDeferredDismiss(item, send);
  };

  return (
    <article className="tv-card" aria-labelledby={`tv-t-${item.signature}`}>
      <div className="tv-card-top">
        <span className={`tv-tag tv-${item.kind}`}>{LABEL[item.kind]}</span>
        <span className="tv-faint">{projectTitle}</span>
      </div>
      {fixing ? (
        <div className="tv-fix">
          <label htmlFor={`tv-fix-${item.signature}`} className="tv-eyebrow">Your wording</label>
          <textarea id={`tv-fix-${item.signature}`} rows={2} value={wording} onChange={(e) => setWording(e.target.value)} />
        </div>
      ) : (
        <h3 id={`tv-t-${item.signature}`}>{item.title}</h3>
      )}
      {item.before && <p className="tv-before">Replaces: <s>{item.before}</s></p>}
      <p className="tv-why">{item.why}</p>
      {item.evidence.length > 0 && (
        <div className="tv-evidence">
          {item.evidence.map((e) => (
            <button key={`${e.source_id}:${e.quote}`} className="tv-quote" onClick={() => onOpenSource(e.source_id)}>
              <q>{e.quote}</q>
              <span className="tv-faint">Open the original</span>
            </button>
          ))}
        </div>
      )}
      <div className="tv-actions">
        {fixing ? (
          <>
            <button className="tv-btn tv-primary" disabled={busy || !wording.trim()} onClick={() => void keep(wording.trim())}>Save my version</button>
            <button className="tv-btn tv-ghost" onClick={() => setFixing(false)}>Cancel</button>
          </>
        ) : (
          <>
            <button className="tv-btn tv-primary" disabled={busy} onClick={() => void keep()}>{KEEP[item.kind]}</button>
            {canFix && <button className="tv-btn" disabled={busy} onClick={() => setFixing(true)}>Fix</button>}
            {t.type === "claim" && <button className="tv-btn" onClick={() => onOpenSource(item.evidence[0].source_id)}>Fix</button>}
            <button className="tv-btn tv-ghost" disabled={busy} onClick={dismiss}>Dismiss</button>
          </>
        )}
      </div>
    </article>
  );
}
```

For a proposal, `Fix` edits the artifact. Initialise `wording` from the artifact instead of the title when `t.type === "proposal"`: fetch `GET /api/v1/proposals/:id` when Fix is pressed and put `data.artifact` into the textarea.

```tsx
// apps/web/today/ProjectCards.tsx
import { useEffect, useState } from "react";
import type { Api } from "./types.ts";

type Props = {
  api: Api;
  projects: { id: string; title: string }[];
  agentNamesByProject: Record<string, string[]>;
  onOpen: (projectId: string) => void;
};

export function ProjectCards({ api, projects, agentNamesByProject, onOpen }: Props) {
  const [facts, setFacts] = useState<Record<string, number | "error">>({});
  useEffect(() => {
    let live = true;
    void Promise.all(
      projects.map(async (p) => {
        try { return [p.id, (await api<unknown[]>(`/claims?project_id=${encodeURIComponent(p.id)}`)).length] as const; }
        catch { return [p.id, "error"] as const; }
      }),
    ).then((rows) => { if (live) setFacts(Object.fromEntries(rows)); });
    return () => { live = false; };
  }, [api, projects]);

  return (
    <div className="tv-projects">
      {projects.map((p) => {
        const n = facts[p.id];
        const agents = agentNamesByProject[p.id] ?? [];
        return (
          <div className="tv-proj" key={p.id}>
            <button className="tv-proj-name" onClick={() => onOpen(p.id)}>{p.title}</button>
            <p className="tv-faint">
              {n === undefined ? "Counting…" : n === "error" ? "Facts unavailable right now" : `${n} ${n === 1 ? "fact" : "facts"}`}
            </p>
            <p className="tv-faint">{agents.length ? `${agents.join(", ")} connected` : "No agent connected"}</p>
          </div>
        );
      })}
    </div>
  );
}
```
