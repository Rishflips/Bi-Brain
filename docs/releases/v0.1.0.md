# BiBrain v0.1.0

First public release. BiBrain is a local-first second brain that keeps AI coding agents caught up. You save a note, or a connected agent writes one when it finishes work. BiBrain keeps the original, works out what changed, and nothing becomes a fact until you keep it.

## Quick start

You need Node.js 24.19 or later on the Node 24 line, and npm 11 or later.

```bash
git clone https://github.com/Rishflips/Bi-Brain.git
cd Bi-Brain
npm ci
npx --no-install bibrain
```

BiBrain builds itself on first use and tries to open your browser already signed in through a one-time link. That automatic opener and its `#pair=` link have not yet been observed on a real machine. If the browser does not open, sign in by hand as the README describes.

To connect Codex, Claude Code or Cursor, see "Connect your agents" in the [README](../../README.md#connect-your-agents).

## Added

- **Today.** One bar to save a note or ask a question (the answer quotes the original). A Brief of at most three things to decide, each with its evidence: Keep, Fix, Dismiss, Undo. Project cards with a Watch switch. When nothing needs you, it says so.
- **Your brain.** One page per project: facts true now (edit as new versions), open questions, originals, goals. Open any fact to see its highlighted source passage and history. Search uses the same ranked recall as agents.
- **Connections and agent recall.** Tiles for Codex, Claude Code and Cursor. Add writes the agent's project files in one step and never changes an existing file. Revoke ends access at once. A prompt hook (an always-on rule file for Cursor) recalls from your brain on every prompt. Seven connector tools; `brain_recall` returns cited hits or says nothing is recorded. Agents leave a session note when they finish, as suggestions for your review.
- **Sorting help (optional, off by default).** Clef, through Ollama or Cloudflare, can suggest "File in Northstar?" (an example project), rank a low-value card lower, or wake a planned review. It stays within your daily and per-note limits.
- **Better search (optional, off by default).** Finds notes by meaning, including across languages such as English and Tamil, with Ollama on your computer or Cloudflare. With it off, nothing is sent for search.
- **Calibration report.** `npm run calibrate` shows where your thresholds fall against your own answers and pushes. It is read-only and never prints note text.
- **Self-hosting.** A Docker Compose package with an HTTPS proxy, for one owner on one Linux host: [Self-hosting](../SELF_HOSTING.md).
- **Licences.** The app is AGPL-3.0-only. The agent connector (`apps/mcp`, `apps/cli`) is Apache-2.0.
- **Dependency fix.** `@hono/node-server` updated to 2.1.5 for GHSA-rmxm-3fg6-px4f.

## Security and privacy

- Originals never change. Corrections are new versions, and Undo never overwrites a later edit.
- Agents only suggest. They cannot accept their own suggestions, and one-step connections cannot delete anything.
- Access is scoped to the projects you pick and can be revoked.
- Provider keys are read only by the background worker. An agent's key stays in BiBrain's data folder, not in your project.
- Model output is checked against a fixed schema and cannot grant access or raise a limit.

## Known limits

- **Owner-run checks still owed:** `npm run proof:search`, `scripts/native-client-proof.ts`, and `npm run calibrate` on real data (so far only on a synthetic brain). Cursor has not been run natively.
- **Not run live:** Cloudflare (sorting and search) and a local Ollama. Also Better search (no real embedding model called, so quality is unmeasured, including Tamil) and the Recall help judge.
- **Run live by the maintainer on Windows:** recall in Claude Code 2.1.283 and Codex 0.156.1, and one Clef sorting check through Ollama Cloud (3 of 3 answers valid, three synthetic notes). The Codex run skipped the one-time hook-trust prompt with a test flag, so the normal `/hooks` approval has not been observed. Cursor has not been run natively.
- **Paused:** the hosted edition and payments. The code is kept but not deployed.
- **Platforms:** tested in CI on Ubuntu and locally on Windows; macOS is untested.
- `npm audit` shows moderate advisories in `glob` and `minimatch` (through `@fastify/static` and ESLint). Fixing them needs a breaking change.
- One-step Add works only in the app on your own computer; a self-hosted copy uses setup by hand. `bibrain` is not published to npm.
