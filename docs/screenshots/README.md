# Browser verification images

`first-use.png` shows the authenticated empty-brain Today experience after local
pairing; the historical filename is retained because the browser suite writes it.
`source-preview.png` shows the source workflow after a real test capture. Both are
captured by Playwright from production assets served by Fastify with the separate
worker running.

The images contain only synthetic test material. They are not owner history, a
live model result, or proof that every release gate passed. Behavioral evidence
and remaining limits are recorded in [BUILD_STATE.md](../../BUILD_STATE.md).
